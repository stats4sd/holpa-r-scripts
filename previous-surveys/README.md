# Custom code for previous surveys

The scripts in this folder relate to one of the HOLPA studies conducted during 2022-24. They can be run to convert the collected datasets into a harmonised structure suitable for inclusion into the HOLPA Platform database.

The key functions include:

- renaming variables related to calculation of agroecology indicators from the old `_#_#_#_#` format to human-readable variables
- calculation of the agroecology indicators based on the data structures from the previous surveys.
